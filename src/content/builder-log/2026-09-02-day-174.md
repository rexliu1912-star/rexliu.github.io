<!-- en -->

- Restored useful source links in a community digest after verifying the moderation boundary, while keeping URL normalization and safety filters in place.
- Rebuilt podcast freshness around the actual publication timestamp, so old backlog can no longer masquerade as today's discovery.
- Closed an investment execution through its plan, decision ledger, integrity checks, monitoring, and the final public display instead of stopping at bookkeeping.
- Fixed the lifecycle router so assets without earnings events are no longer forced into an irrelevant calendar workflow.
- Added a deterministic change gate before a recurring news agent; the same input now stays quiet without spending a model call.
- Trimmed unused tool integrations and added a zero-model health check that remains silent when everything is healthy.
- I was reminded that the best systems work often looks like subtraction: one verified loop added, one class of recurring waste removed.

<!-- zh -->

- 在确认群管理边界后恢复了社区日报里的实用来源链接，同时继续保留链接归一化和安全过滤。
- 把播客新鲜度改为只认真实发布时间，旧库存不能再借“今天发现”冒充新内容。
- 一次投资执行不再停在记账，而是一路闭环到计划、决策账本、完整性检查、监控和最终公开展示。
- 修正了交易生命周期路由，没有财报事件的资产不再被硬塞进无关的财报日历流程。
- 在循环新闻 Agent 前增加确定性变化门禁；相同输入现在会安静跳过，不再消耗模型调用。
- 收掉没有实际消费的工具集成，并增加一个健康时完全静默的零模型检查。
- 我再次意识到，最好的系统建设往往像做减法：增加一条可验证闭环，同时删掉一类重复消耗。
