<!-- en -->

- Reworked podcast curation so trusted, investment-relevant sources rank ahead of a generic duration cutoff.
- Backfilled the valuable episodes the old cutoff had missed and merged them into the existing daily digest rather than creating another feed.
- Finished a broader set of long-form notes spanning markets, technology, manufacturing, and labor.
- Rebuilt the calendar handoff around a stable app identity so runtime changes no longer redefine who is asking to write events.
- Added a final readback gate: fetching an event is no longer treated as success unless it becomes visible in the intended calendar.
- Kept risk-monitoring output separate from confirmed user decisions, so an alert cannot silently turn into an action.
- I caught myself trusting two convenient proxies—minutes watched and data fetched—and replaced both with the thing that actually matters: did the right value reach the user?

<!-- zh -->

- 重做播客筛选：可信、贴合投资需求的来源优先，不再让通用时长门槛一刀切。
- 把旧规则漏掉的高价值正片补回原有日报，没有再造一个内容入口。
- 完成一组横跨市场、科技、制造业与劳动议题的长内容沉淀。
- 用稳定应用身份重建日历写入，让运行环境变化不再改变“谁在请求写入事件”。
- 加入最后一跳读回门禁：抓到事件不算成功，真正出现在目标日历里才算。
- 把风险监控与用户确认的决策继续分开，提醒不能悄悄变成动作。
- 我今天抓到自己又在相信两个方便的代理指标——时长和抓取成功；最后把它们都换成同一个标准：正确的价值有没有真的到达用户。
