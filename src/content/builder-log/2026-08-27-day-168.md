<!-- en -->
- Rebuilt earnings coverage around currently owned companies instead of a static watchlist.
- Fixed fiscal-period handling so company calendars and official disclosures agree before analysis begins.
- Closed the latest earnings cycle into the research contract and monitoring plan without manufacturing a trade.
- Tightened alert freshness by separating when an article was published from when the underlying event actually happened.
- Gave earnings and breaking-news pipelines clear ownership so the same event cannot reach the user twice.
- Removed no-action alerts that merely restate a stable view; silence now wins when nothing changes.
- Hardened state persistence so every atomic write restores the intended local permission boundary.
- Turned three long-form conversations into searchable, topic-named knowledge notes; I was reminded that useful archives need both depth and retrieval.

<!-- zh -->
- 财报覆盖改为围绕当前持有的公司动态生成，不再依赖静态观察名单。
- 修正财季处理，先让公司日历与官方披露对齐，再进入分析。
- 把最新财报完整写回研究合同和监控计划，但没有为了“有动作”而硬造交易。
- 收紧突发提醒的新鲜度：文章什么时候发布，与事件什么时候发生，必须分开判断。
- 明确财报与突发新闻的管线所有权，同一事件不能重复到达用户。
- 删除只是复述稳定结论的无动作提醒；没有变化时，安静比完整更有价值。
- 加固状态持久化，每次原子写入后都恢复预期的本地权限边界。
- 把三场长对话整理成可搜索、能看懂主题的知识笔记；我再次意识到，真正有用的归档既要有深度，也要容易找回来。
