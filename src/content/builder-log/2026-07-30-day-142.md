<!-- en -->

- Audited the latest Hermes capabilities and chose not to adopt a feature that does not fit the current gateway-first setup.
- Turned a multi-month trading retrospective into five pre-trade guardrails instead of leaving it as hindsight.
- Added thesis and invalidation cards across the active portfolio so conviction now has explicit failure conditions.
- Rebuilt stale monitoring rules around current position state rather than trusting old cost assumptions.
- Added a weekly portfolio health check that surfaces concentration, invalidation distance, and rule violations.
- Retired ClawFeed and removed the stale archive, scripts, and references around a system we no longer use.
- Redesigned NewsLiquid to explain why an item matters and suppress neutral updates with no decision impact.
- I was reminded that a retrospective only compounds when it changes the next decision before it happens.

<!-- zh -->

- 审计了最新版 Hermes 能力，并明确放弃一个不适合当前 gateway-first 架构的功能。
- 把数月交易复盘压成五条交易前门禁，没有让它停在事后解释。
- 为当前组合补齐 thesis 与 invalidation 卡，让每份信念都有明确失效条件。
- 按当前持仓状态重建过期监控规则，不再信任旧成本假设。
- 加入每周持仓体检，直接暴露集中度、失效线距离和规则违规。
- 退役 ClawFeed，清掉不再使用的 archive、脚本和残留引用。
- 重做 NewsLiquid：只解释为什么值得关注，过滤对决策没有影响的中性更新。
- 我再次确认，复盘只有在下一次决策发生前改变入口，才会真正复利。
