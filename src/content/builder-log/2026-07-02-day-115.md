<!-- en -->

- Cleaned up the calendar layer so routine market events stay useful instead of piling up into background noise.
- Split the content digest flow so podcast processing can keep running without dragging a full reading digest along with it.
- Tightened portfolio review by making valuation context show up when the chart exists, not just when someone remembers to ask for it.
- Turned a long scanned essay into a structured knowledge asset, then pulled out the real lesson: insight only matters when it connects to action and value exchange.
- Updated the signal scorecard so the system keeps learning which signal shapes deserve weight and which ones should be treated with suspicion.
- Clarified the Apple Calendar boundary: create, edit, bulk import, and export can be automated; sharing across Apple IDs still needs a human click.

<!-- zh -->

- 清理日历层，把重复和过期的市场事件往下砍，让提醒重新变成提醒，而不是背景噪音。
- 拆开内容 digest，让播客流程继续跑，但不再顺手带出一整份阅读日报。
- 收紧 portfolio review：估值图当天存在就必须出现，不靠下一次人工追问才补上。
- 把一篇长扫描文章变成结构化知识资产，并提炼出真正有用的部分：看懂不够，必须接上行动和价值交换。
- 更新信号回测，让系统继续区分哪些信号值得加权、哪些信号应该保持怀疑。
- 明确 Apple Calendar 边界：创建、编辑、批量导入、导出都能自动化；跨 Apple ID 共享仍然需要人点一下。
